# 大模型能力落地路线图（LLM Roadmap）

你的 ALGORITHM.md 已经精准标出了 6 个"改进入口"，本层把它们做成**可插拔、带缓存、无 Key 自动降级**的模块，
全部在 。设计原则：LLM 是增强不是依赖，断网/无 Key 时管线照常跑。

## 六个杠杆点（按投入产出比排序）

| 编号 | 杠杆点 | 现状痛点 | LLM 做法 | 接入成本 | 预期收益 |
|---|---|---|---|---|---|
| **L1** | 向量化  | TF-IDF 只认字面，"省电费"≠"用车成本低" | 调用 Embedding API 替换  | 低（同接口） | ★★★★★ 聚类/建边/争议边全链路提质 |
| **L2** | 场景打标  | DIMS 词典手写，换话题要重写 | LLM 离线批量打多维倾向，换话题只换 dims 列表 | 低 | ★★★★ 彻底解决"硬编码词典"短板 |
| **L3** | 立场判定  | 关键词法 75% 准确率，已降级 | LLM 三分类+置信度，处理反驳式提及/条件句 | 低 | ★★★ 面板标签可信 |
| **L4** | 簇命名  | 簇名靠"场景轴+高频词"拼接 | LLM 生成可读派别名 | 极低 | ★★ 演示故事性 |
| **L5** | 被低估解释  | 只标 gem 不解释 | LLM 一句话"干货点+被埋没原因" | 低 | ★★ 产品说服力 |
| **L6** | 全文增强  | ContentText 是摘要，判别力受限 | 抓全文/LLM 扩写后再向量化 | 中 | ★★★ 补足摘要短板 |

## 工程护栏（已内置）
- **缓存**： 按输入哈希落盘 ，离线跑一次，重复跑零成本。
- **降级**：每个函数 ，无 Key 或调用失败返回中性值， 原样返回 nodes，**绝不断链**。
- **批量+JSON 模式**： 强制结构化输出，便于下游解析。
- **厂商无关**： 兼容 OpenAI/通义/DeepSeek/Moonshot/本地 Ollama，换厂商只改 3 个环境变量。

## 后续可深挖方向
1. **观点抽取流水线**：LLM 把每条回答结构化为 {主张, 论据, 场景取值, 情绪}，图谱边直接用"主张相似度"而非字面相似。
2. **自然语言查询**：侧边栏加输入框，"只看有桩党谈残值" → LLM 转成社区过滤条件。
3. **争议边叙事**： 选出的对立对，LLM 生成"分歧本质"摘要（你已发现是样本不对齐，LLM 可自动说出）。
4. **GraphRAG**：把整张图喂给 LLM 做"这个题社区主流观点是什么"的问答。
